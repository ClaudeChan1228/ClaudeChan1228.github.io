SAP ABAP 长文本读取完整指南

本文最后更新于 2026-07-28

概述

在 SAP 系统中，许多业务对象都包含长文本信息，如采购订单的备注、销售订单的条款、物料主数据的说明等。这些长文本存储在表 STXH（文本抬头）和 STXL（文本行）中，通过标准函数 READ_TEXT 进行读取。

本文梳理了常见业务场景下的长文本读取方法，提供可复用的代码模板。

核心函数：READ_TEXT

READ_TEXT 是读取长文本的标准函数模块，主要参数说明：

参数 说明 示例
CLIENT 客户端（通常为 sy-mandt） 800
ID 文本 ID（标识文本类型） ‘F01’
LANGUAGE 语言 sy-langu / ‘ZH’
NAME 文本名称（通常是对象键） 采购订单号
OBJECT 文本对象 ‘EKKO’ / ‘VBBK’
LINES 返回的文本行表（TYPE TABLE OF TLINE） lt_lines

常用采购订单文本 ID：

  • F01 - 采购订单抬头文本（Object: EKKO）
  • F02 - 采购申请抬头文本（Object: EBAN）
  • F03 - 报价单抬头文本（Object: EKKO）
  • F05 - 采购订单行项目文本（Object: EKPO）
  • F06 - 采购申请行项目文本（Object: EBAN）

2. 销售订单（SO）长文本

常用销售订单文本 ID：

  • 0001 - 销售订单抬头/行项目文本（Object: VBBK/VBBP）
  • 0002 - 内部备注
  • Z001 - 交货抬头文本（Object: VBBK，交货单号）
  • Z002 - 发票抬头文本（Object: VBBK，发票号）

3. 物料主数据长文本

常用物料文本 ID：

  • GRUN - 基本数据文本（Object: MATERIAL）
  • BEST - 采购订单文本（Object: MATERIAL）
  • KAUF - 内部备注（Object: MATERIAL）
  • LAKT - 销售文本（Object: MVKE，需指定销售组织+分销渠道）

最佳实践

  1. 异常处理：务必检查 sy-subrc，not_found = 4 表示文本不存在（正常情况）
  2. 语言处理：多语言环境下，显式指定 sy-langu 或目标语言代码
  3. NAME 格式：注意不同对象的 NAME 格式要求（前导零、右对齐、组合键等）
  4. 性能优化：批量读取时，考虑使用 READ_TEXT 的批量版本或直接查询 STXH/STXL 表
  5. 文本拼接：使用 && 操作符或 CONCATENATE，注意 tdline 长度为 132 字符
  6. 换行处理：如需保留原始格式，使用 cl_abap_char_utilities=>newline 拼接行

参考表

表名 说明
STXH 文本抬头（包含 OBJECT/ID/NAME/LANGU 等索引字段）
STXL 文本行内容（CLOB 存储）
THEAD 文本抬头结构（用于函数参数）
TLINE 文本行结构（132 字符）
TTXID 文本 ID 配置表

总结

READ_TEXT 是 SAP 系统中读取长文本的标准方法，掌握不同业务对象的文本 ID 和 NAME 格式是关键。建议在项目中维护一个文本 ID 配置文档，方便快速查阅和复用代码。
